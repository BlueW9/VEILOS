About VEILOS

VEILOS is a privacy-first Linux distribution for desktops and laptops. It is built on Debian Stable, so it inherits Debian’s long-term security updates, and it uses the GNOME desktop. English and Arabic are built in.

It starts with strong defaults instead of settings you have to hunt for: a firewall that blocks incoming connections, encrypted DNS, automatic security updates, and a set of respected privacy tools installed and ready to use.

Protection

  • Firewall that blocks all incoming connections by default
  • Encrypted DNS through Quad9, with an on/off switch
  • AppArmor and kernel hardening
  • ClamAV with on-access scanning
  • Screen lock with a password
  • Full-disk encryption available at install

Updates and privacy

  • Automatic security updates from Debian and the vendors’ own repositories
  • Daily updates for Flatpak apps
  • No telemetry, no crash reporting, no popularity contest
  • Location services and usage statistics off

Apps, ready to use

  • LibreWolf, the default browser
  • Proton VPN, Proton Pass and Proton Authenticator
  • Signal and SimpleX Chat
  • Standard Notes and AsterMail
  • LibreOffice, VLC and FreeTube

  • Freedom of conscience

Download

VEILOS 26.11 for 64-bit computers (amd64). The image is about 5 GB, and GitHub limits each file to 2 GB, so it comes in three parts that you join after downloading.

Open the download page

Free software under the GPL-3.0 license.

Direct links

  • veilos-26.11-amd64.iso.part00
  • veilos-26.11-amd64.iso.part01
  • veilos-26.11-amd64.iso.part02
  • SHA256SUMS.txt (checksum to verify your download)

Join the parts on Linux or macOS

cat veilos-26.11-amd64.iso.part* > veilos-26.11-amd64.iso
sha256sum -c SHA256SUMS.txt

Join the parts on Windows

Open Command Prompt in the folder with the downloads:

copy /b veilos-26.11-amd64.iso.part* veilos-26.11-amd64.iso
certutil -hashfile veilos-26.11-amd64.iso SHA256

The result must match the value in SHA256SUMS.txt. Then write the ISO to a USB drive, for example with Rufus in DD Image mode, and start your computer from it.
